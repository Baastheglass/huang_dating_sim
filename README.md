# Shift: A Jensen Huang Dating Sim

You're a spy trying to charm Jensen Huang into handing over his next chip formula. Press **Shift** to change your race until you find the one he likes, but every shift lowers his attraction a little.

## How to start the game

Requires Python 3.

1. Open a terminal in this folder.
2. Create and activate a virtual environment:
   ```bash
   python3 -m venv env
   source env/bin/activate        # Windows: env\Scripts\activate
   ```
3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the game:
   ```bash
   python game.py
   ```

## Controls

| Input | What it does |
|---|---|
| **Shift** | Change your race (costs attraction) |
| **Mouse click** | Pick an action |
| **Close window** | Quit |
